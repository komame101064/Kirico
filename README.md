# Kirico

製造現場で使う加工計算と現場メモを、ひとつにまとめたWebアプリです。
ブラウザで `index.html` を開くだけで動きます（インストール不要・1ファイル）。

## できること

| 区分 | 内容 |
|---|---|
| 電卓・単位 | iPhone風の電卓（√・π・2乗・履歴）、インチ⇄ミリ、度分秒⇄度、18種類の単位変換（長さ・圧力・トルク・温度など） |
| 加工条件 | 旋削・フライス・ドリル・タップ・研削（円筒／平面）の回転数、送り速度、加工時間、動力、仕上げ面粗さ、砥石周速度 |
| 図面・寸法 | 直角三角形、テーパー角、PCD穴位置（座標表）、サインバー、円弧・弦 |
| 記録ノート | 計算結果とメモを図番・機械・タグ付きで保存、検索、重要マーク、条件の呼び出し、CSV書き出し |

## 使い方

- そのまま開く：`index.html` をブラウザで開く
- GitHub Pages で公開：リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存

## データの保存先

記録ノートと入力値は、使っている端末のブラウザ（localStorage）に保存されます。
端末やブラウザを変えると引き継がれません。必要に応じて「CSVファイルで保存」で書き出してください。

## ご注意

推奨切削速度・速度比などは一般的な目安です。実際の条件は工具・砥石メーカーのカタログ値と、機械の剛性・クーラント条件に合わせて調整してください。砥石は表示された最高使用周速度を超えて使わないでください。
